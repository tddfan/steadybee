# Retired research workspace

The single active app is `prototype/asset-canvas.html` at the repository root. This archive is not included in `dist` or linked from the current interface. Old public page routes redirect to the main app.

Retained for useful functionality and research history, not as a competing app:
- validated optional device save, JSON backup/import and deletion;
- printable brief and workings/CSV export;
- explicit DB pension capture, example end-age choices and authored examples;
- original landing-page design and customer-research flows.

These capabilities are not automatically available in the current version. Review them for migration before deleting this reference. No real financial data is included. `tests/test_state.mjs` and `tests/test_app_updates.cjs` in the active test suite still exercise its pure logic. The old browser journey suite is archived with its app; use the current money-picture journey for active UI checks.
