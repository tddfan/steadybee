# Phase 5: goal-aware review and supported insights

The approved baseline/Lifeline strategy now has a goal-led Plan foundation. This increment connects the chosen goal to calculated scenario results and the reviewed AI request, and adds a repeatable household review. Work remains on `codex/asset-constellation-demo`, uncommitted until the founder has reviewed it.

## Delivery

1. Create `prototype/plan-review.mjs` for strict goal validation, a shared numerical goal checkpoint, same-date baseline differences, opening-year ISA input checks and a small dated review history. Use the monthly engine's outputs. Dates outside its horizon produce an unavailable checkpoint; they never borrow the last projected value. Convert comparable paths to the same explicitly dated money basis. Funding gaps and cash reserve constraints stay separate from the goal measure.
2. Extend the existing insights settings with optional review cadence/history. Continue to accept old settings and frozen baseline documents. Record completion only on the user's explicit action. Mark later changed inputs; selecting a chart date must not change the review fingerprint. No background reminder or external message is created.
3. Add a version 3 anonymous AI brief containing the goal type/person/date/amount, its numerical checkpoint, each supported candidate's checkpoint, reserve trade-offs and same-date baseline differences. Preserve versions 1 and 2. Reject unknown fields and free text. All narrative and displayed figures remain validated/reviewed; the AI chooses only supplied candidates.
4. Add a compact review section to Plan: what changed, next review, input checks, and access to calculations. Show goal effects in experiment previews and AI-selected comparisons. ISA checks apply only to supplied subscriptions for the recorded 2026–27 tax year, use the overall limit, and do not assume eligibility or flexible-ISA replacement rules. Pension, dividend and capital-gains allowance optimisation remains explicitly unassessed.
5. Make the Lifeline scenario comparison show frozen baseline, current path and temporary experiment together. Keep previews through date/zoom changes; invalidate them when financial inputs or assumptions change. Preserve explicit Apply/Discard/Undo and exclude preview state from saving/export labels.
